## 三、功能测试（55 例）

### `functional/queries.test.ts`（内存库，30 例）
- **列表筛选（8）**：默认 7 条按 `release_date` 降序、`status=watched`(4)/`plan`(3)、`media_type=tv`(3)、`year=2023`(2)、`genre` 模糊（`/` 分隔）、`country` 模糊（多值拆分）、`q` 全文、组合筛选。
- **排序（4）**：默认降序 / 升序 / `douban_rating` 降序（NULLS LAST）/ `tmdb_rating` 升序（NULLS LAST）。
- **分页（4）**：`limit=2` 前 2 条、`page=2` 偏移不重复、`limit=0` 不限制、`page<1` 视为 1。
- **维度（4）**：`listFacets` genres/countries/years 拆分去重排序、`invalidateFacets` 重置一致性。
- **详情（2）**：`getRecord` 联表拼接 / 不存在返回 null。
- **年报（3）**：`getReport` 总览计数与均值 8.5、years 分组降序、年份聚合 avg 7.5。
- **年份下钻（5）**：按年取 watched、按月分桶 `YYYY-MM` 降序、无记录 `total=0`、仅统计 watched（plan 不计入）。

### `functional/routes.test.ts`（Route Handler 直调，19 例）
- `/api/records` (GET)：结构返回、`status=plan` 筛选、非法参数 → 422（`参数校验失败`）、非法枚举 → 422。
- `/api/stats` (GET)：年报结构、带 `Cache-Control: s-maxage=60`。
- `/api/records/[item_id]` (GET)：命中返回 `{item,record}`、未命中 → 404、缺 id → 400。
- `/api/stats/[year]` (GET)：合法年份按月数据、非法 `abcd`→400、**4 位正则边界 6 组**（`202`/`20261`/`20.5`/` 2024`/`+2024`/`2026abc` 全 → 400）、合法 `2024`→200、**中英文错误文案**（`zh-CN`→`无效年份`，`en-US`→`Invalid year`）。

### `functional/security.test.ts`（中间件，6 例）
- 全局限流：超阈值 → 429（前两次放行 + 带 `Retry-After`）、不同 IP 互不影响。
- 认证防爆破：连续错误密码 → 429；正确密码放行并清空失败计数。
- 公开模式：未设 `SITE_PASSWORD` 直接放行。
- 错误脱敏：401 响应体不含 `.ts`/堆栈/`stack`，含 `Authentication required`。

> 限流 Map 已加 `MAX_BUCKETS=2000` 上限与近似 LRU 淘汰（`middleware.ts`），安全测试用 `vi.resetModules()` 保证跨用例干净状态。
