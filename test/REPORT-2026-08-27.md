## 三、功能测试（75 例）

### `functional/queries.test.ts`（内存 `:memory:` 库，33 例）
- **列表筛选（8）**：默认降序、`status=watched/plan`、`media_type=tv`、`year=2023`、`genre`/`country` 模糊（多值拆分）、`q` 全文、组合筛选。
- **排序（4）**：默认降序 / 升序 / `douban_rating` 降序（NULLS LAST）/ `tmdb_rating` 升序（NULLS LAST）。
- **分页（4）**：`limit=2` 前 N 条、`page=2` 偏移不重复、`limit=0` 不限制、`page<1` 视为 1。
- **维度（4）**：`listFacets` genres/countries/years 拆分去重排序、`invalidateFacets()` 重置一致性。
- **详情（2）**：`getRecord` 联表拼接 / 不存在返回 null。
- **年报（3）**：`getReport` 总览计数与均值、`years` 分组降序、年份聚合均值。
- **年份下钻（5）**：按年取 watched、按月分桶 `YYYY-MM` 降序、无记录 `total=0`、仅统计 watched。

### `functional/routes.test.ts`（Route Handler 直调，21 例）
- `/api/records` (GET)：结构返回、筛选、非法参数 → 422、非法枚举 → 422。
- `/api/stats` (GET)：年报结构、`Cache-Control: s-maxage=60`。
- `/api/records/[item_id]` (GET)：命中返回 `{item,record}`、未命中 → 404、缺 id → 400。
- `/api/stats/[year]` (GET)：合法年份按月数据、`abcd`→400、4 位正则边界 6 组全 → 400、`2024`→200、中英文错误文案。

### `functional/security.test.ts`（中间件，21 例）
- 全局限流：超阈值 → 429（放行若干次后持续 429、带 `Retry-After`）、不同 IP 互不影响。
- 认证防爆破：连续错误密码 → 429；正确密码放行并清空失败计数。
- 公开模式：未设 `SITE_PASSWORD` 直接放行。
- 错误脱敏：401/429/5xx 响应体不含 `.ts`/堆栈/`stack`，含友好文案。
- 用 `vi.resetModules()` 重载中间件模块，清空模块级计数 Map，保证跨用例干净状态。

> 限流 Map 已加 `MAX_BUCKETS` 上限与近似 LRU 淘汰（`middleware.ts`），安全测试通过模块重载隔离。
