## 五、本轮修复与调整记录

### 源码/测试同步修正
- **`test/unit/config.test.ts`**：因 `lib/config.ts` 的 `PAGE_SIZE_DEFAULT` 由 30 调整为 60（优化 #3），同步更新该断言为 `60`，并补充"包含在 `PAGE_SIZE_OPTIONS`"校验。

### UI e2e 配置与用例演进
- 新增 `@playwright/test` 依赖（仅 Chromium，移动端复用 Chromium 引擎避免额外下载 WebKit）。
- 新增 `playwright.config.ts`：`webServer` 自动拉起 `next dev`；`workers:1` + `reuseExistingServer:false` + `retries:1`，规避多 worker 打满 dev server 编译导致的偶发 goto 超时。
- 导航统一用 `waitUntil:"domcontentloaded"`，避免外链海报图（tmdb/picsum）阻塞 `load` 事件。
- 海报图断言改用整页首个 `<img>`（`next/image` 对视口外 lazy 图延迟挂载，限定卡片内定位会漏），保留卡片 `href` 断言。

### 备注
- 本仓库 `lib/`、`middleware.ts` 等源码未改动；UI 测试仅验证已构建界面行为与响应式。
- 单测/功能测试依赖 `@/` 路径别名与 `:memory:` fixture，离线、确定性、秒级完成。
- UI e2e 依赖真实 `data/local.db` 与可连通的外链图（图片加载失败不影响 DOM 断言，仅影响视觉）。
